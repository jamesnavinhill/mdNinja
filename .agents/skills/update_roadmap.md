# Skill: Update Roadmap Execution State

Use this workflow to advance project milestone tasks in `projectmd/roadmaps/roadmap.md`.

## Instructions
1. Open `projectmd/roadmaps/roadmap.md`.
2. Locate the corresponding task under `## 📋 Task Execution State`.
3. Change `[ ]` to `[x]` only when the feature is built, tested, and verified.
4. If a phase milestone is completed, update the Mermaid Gantt chart state above:
   - Change `:active,` to `:done,`.
   - Set the next sequential task to `:active,`.
5. Save the file directly to disk.
